Features

Everything you need to evaluate LLMs

From simple benchmarks to advanced red-teaming and RAG evaluation pipelines.

📊

Benchmarking Runner

Run prompts across multiple models simultaneously. Compare quality, cost, and latency side-by-side in real time.

🎯

Evaluation Engine

Automatic metrics, LLM-as-judge scoring, and human evaluation workflows. Fully customizable rubrics and criteria.

🔴

Red Teaming

Automated adversarial attack testing: jailbreaks, prompt injections, PII extraction, toxicity, and encoding bypasses.

🏟️

ELO Arena

Head-to-head model comparisons with ELO rating system. Find the best model for your specific use case automatically.

📚

RAG Pipeline Testing

Upload documents, generate pgvector embeddings, and evaluate retrieval quality across different chunk configurations.

🤖

Agent Testing

Execute and trace multi-step AI agents. Monitor tool calls, step counts, cost, and success rates end-to-end.
